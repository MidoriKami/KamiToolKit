# KamiToolKit

C# library wrapping Final Fantasy XIV's native UI (`AddonToolKit`) for Dalamud plugins.

## Overview

KamiToolKit provides an easy to use API for generating ui elements that are baked into the games ui systems directly, and behave as any other native windows would.

## Getting Started

The recommended way to use this API is via [NuGet](https://www.nuget.org/packages/KamiToolKit)

Alternatively if you are intending to contribute to this API, adding KamiToolKit as a submodule allows you to easily PR changes.
